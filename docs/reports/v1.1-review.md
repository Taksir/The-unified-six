# v1.1 report: translation review pass

Generated from `data/m4/review.jsonl` and `data/release/hadith.jsonl`.

## Method

Every v1.0 translation (13,021) was re-read against the Arabic **with diacritics** (v1.0 was
translated from diacritic-free text; one spot-check error came from that) by Claude Sonnet 5.5
at high effort, Batch API, ≤ 500 Arabic words per request (`m4.stage_review`). The model was
told to report **only meaning errors** — omissions, additions, wrong subject/object, reversed
sense, a mistranslated ruling — and to return the full corrected segments, aligned one to one
with the Arabic. Replies that said "no error" or changed nothing were discarded.

Pilot on the 50 hadith of the M4 Opus spot-check (3 known errors): one run at medium effort
and one at high each caught one known error, different ones; high effort made no stray edits,
so the full run used high. Expect the pass to have fixed roughly a third to a half of the
meaning errors (v1.0 estimate: ~6 % of hadith, i.e. ~750), not all of them.

## Result

Each corrected entry carries `review_fix` (what was wrong) in `hadith.jsonl`; `translation`
gains `machine_reviewed` and `corrected_in_review`. Corrected entries keep clause-level italics.
