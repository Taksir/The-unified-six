12 builds = 2 editions × 2 languages × (hadith, appendix, combined). Each volume is a
separate PDF (17,506 pages in 38 volumes); the four
"combined" files concatenate them. About 0.5 GB in all, so they are not committed:
`.github/workflows/release.yml` rebuilds everything from the committed data (no API key) and
attaches it to a GitHub Release when a `v*` tag is pushed.

Each entry: English (italics for additions), Arabic (EN + AR builds), and a bracket with
stars, the muttafaq/one-Ṣaḥīḥ badge, book letters, al-Tirmidhī's grade, ≈ for uncertain
groupings, the appendix number and a "report" link that opens a pre-filled GitHub issue.
Volume 1 of every build carries the reading guide, the machine-translation and
machine-grouping disclaimers, numbering schemes and the license.
