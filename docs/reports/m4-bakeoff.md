## Decision

**Sonnet 5.5, medium effort, packed** — the owner's standing choice, now measured.
Bake-off spend: $0.15 translation + $0.69 judging (both runs).
Packed Sonnet live cost on the sample implies ≈ $0.000023 per Arabic word on the Batch API,
≈ $15 for all 641,291 words; the batch pilot (below, `docs/STATUS.md`) measures it directly.
