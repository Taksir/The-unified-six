# M6 report: website

Generated by `python -m u6 m6 build` + `python -m pagefind --site site` (Pagefind 1.3.0).
Deployed by `.github/workflows/pages.yml` on every push to `main`.

## What it is

A static site (plain HTML/CSS, ~20 lines of JS, no framework, no trackers, no secrets) at
`https://taksir.github.io/The-unified-six/`, built from `data/release/` — the same data as
the PDFs. All links are relative.

| section | pages |
|---|---|
| `/h/<U6-id>/` | 13,003 hadith pages: English + Arabic (italics = additions; tap one to highlight the narrations that carry it), bracket (stars, badge, books, Tirmidhī grade, ≈, edition A/B numbers), sources table (number, chapter, role, narrator, sunnah.com link), full Arabic text with chain for every member, topics, see-also, v1.1 correction note, report-an-issue link |
| `/topics/` | 33 topics, ★6 → ★1, 150 per page |
| `/stars/` | ★6 … ★1, by topic within |
| `/books/<book>/` and `/books/<book>/<n>/` | every narration number redirects to its entry (e.g. `books/bukhari/1/`) |
| `/search/` | Pagefind: English and Arabic, filters for topic, books, stars |
| `/`, `/about/` | introduction, disclaimers, downloads, method, license |

## Search

Each hadith page indexes, invisibly, the Arabic of **every** member narration (not only the
version shown), in two forms: without diacritics, and without diacritics with alef/ya unified —
so "الأعمال بالنيات", "الاعمال بالنيات" and the vocalised text all find the entry. Checked:
"intentions" 63 results; "إنما الأعمال بالنيات" → U6-00127 (Bukhārī 1); "من شهد الجنازة" → U6-00001.

## Checks

- Browser (Chromium, Playwright): hadith page at 1280 px and 390 px, light and dark; home on
  phone; search in English and Arabic; book-number redirect. No console errors.
- Size: 177 MB (47,311 HTML files incl. 34,150 redirect stubs, Pagefind index), under the
  1 GB Pages limit. Build ≈ 20 s + index ≈ 60 s.
- `tests/test_site.py`: relative paths, slugs, commentary cut, italics.

## Known limits

- The text shown is the representative chosen in M1–M3. Where the isnad/matn split was wrong
  (~10 % of narrations, M0), the displayed text can begin with part of a chain — e.g. U6-00127
  (Actions are by intentions) shows al-Nasāʾī's version starting "read to him while I was
  listening…". Fixing it needs a better split (future work); search is unaffected.
- Arabic search is word-exact: "النيات" does not match "بالنيات" (attached prepositions).
