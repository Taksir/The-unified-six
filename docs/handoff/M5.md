## Work

1. **Clean the stubs first.** 98 representatives have ≤ 3 Arabic words (221 ≤ 5), e.g.
   بِهَذَا, جَلَسْتُ: split leftovers or "same as previous" references. Attach each to its
   parent hadith (usually the preceding narration in the same book) or drop it from the
   main text, keeping every narration traceable in the appendix. Rules, no LLM.
2. **Dataset:** `narrations.jsonl`, `hadith.jsonl` (with `en`, `topic`), `concordance.csv`
   as specified in `docs/PROPOSAL.md` §3.2, plus a changelog and a machine-translation
   disclaimer.
3. **12 PDF builds** (§3.1): Editions A (by attestation) and B (by topic) × English /
   English + Arabic × hadith / appendix / combined, split into volumes; a "Report an issue"
   link per hadith.
4. **Release:** GitHub Release + Zenodo DOI.
